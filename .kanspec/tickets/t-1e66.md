start/init on a non-main integration branch: warn or ask

## Steps

`start` cuts the ticket branch from the configured main. On the trial branch this silently would have produced a branch with no `.kanspec/`; the fix was `main = "kanspec-migration"` in config, which nothing suggested. `status` also warned 'main cannot see the board' with a fix naming `.gitkeep`. `init` should ask which branch integrates; `start` should refuse or warn when HEAD is not on main's history.
