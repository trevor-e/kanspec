Typed gate codes instead of string codes inside the closed KsError enum

## Steps

The eight closed KsError shapes push every new refusal through `KsError::gate("some_code", ...)`, so the codes hooks and agents branch on (`not_landed`, `ci_reader_v02`, `proposal_closed`, ...) are untyped strings nothing checks exhaustively, and KsError::Git's `cmd`/`exit` fields are write-only. Introduce a GateCode enum (serialised as the same snake_case strings so --json is unchanged), make gate() take it, and either surface or drop the Git fields.
