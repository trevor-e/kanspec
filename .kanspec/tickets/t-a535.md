Ctx should not read process globals: invoked_as, color, env::args

## Steps

`cli::set_invoked_as`/`invoked_as()` and the color choice were process globals, and `Ctx::invocation()` read `std::env::args()`, which is why every web-UI verb logged itself as `kanspec up --port ...` until the server started overriding `ctx.invocation`. Ctx was designed for one CLI caller and the server re-opens it per request. Make Ctx fully self-describing (invoked_as, invocation, out mode as plain fields set by whoever builds it) and remove the globals, so a second caller such as the server or a test needs no override hooks.
